# M10: Offseason engine and schedules

## Plan
1. Sortable tables (post-M23 1.2): one shared component for every table, sorted by up to four columns
   from the headers or a Sort panel: unit tests for the order, layout tests for the headers, the
   announcement, focus, and the panel at 320 pixels with 200% text.
2. Changes with causes (post-M23 1.1, post-M42 1.1): every rating change goes through one function with
   its cause, and roster and depth chart changes are logged as events with reasons: unit tests.
3. Schedules for 2027 on (spec 5.2): rotations from the 2026 seed year and a week grid: unit tests over
   a 12-year window.
4. The offseason calendar (spec 4.1): every phase from staff through final cutdown, the new league year
   (rollover, cap growth, carryover), expirations, retirements (10.7), a stand-in rookie class until
   M11's draft, and the next season: unit tests per phase, a layout test through an offseason.
5. Progression and regression (10.5) with the curve tables and speed sliders, and training focus
   (weekly and offseason) with auto: unit tests, layout tests for Settings and training.
6. The re-sign window (11.4, 11.5): extensions, tags, RFA tenders, 5th-year options, for the user and
   the AI: unit tests for amounts, a layout test.
7. OTAs, training camp, preseason, and final cutdown: unit tests, a layout test.
8. Close: seasons chained through the weekly loop with aging metrics, a 10-season run, reviews, report.
