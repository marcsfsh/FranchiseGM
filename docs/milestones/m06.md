# M6: Calibration harness v1

## Plan
1. Replay core in `src/engine/calibration`: generated leagues replay the 2026 regular season with seeded
   streams and yield compact game, team, player, and injury facts, plus a fit experiment that gives each
   starter his best or worst scheme fit at random: proven by unit tests (fixed seeds replay exactly; facts
   match the box scores).
2. Metrics, targets, and reports: games and seasons (home field, favorites by rating gap, margins, win
   spread and extremes), league stats, leaders and shares, injuries, and effect sizes (fit, weather);
   `calibration/targets.json` with sourced pass and warn bands and wide CI bands; Markdown and JSON reports
   that mark each metric pass, warn, fail, or not measured yet: proven by unit tests on synthetic samples.
3. Runner: `npm run calibrate -- --seasons N` spreads replays over worker threads, writes the report to
   `calibration/reports/`, and prints the summary; CI runs 20 seasons with the CI bands: proven by a run.
4. Tuning: 100-replay runs with one-file changes to `src/engine/tuning.ts`, each logged in
   `docs/CALIBRATION.md`, until game and stat metrics pass: proven by the final report.
5. In-app runner (spec 23.1): a calibration job in the worker and a hidden dev menu in Settings (seven taps
   on the version, always on in the debug build) with a progress bar and the report: proven by a layout test.

## Report
- Built: `npm run calibrate` (worker threads, about 2 minutes for 100 seasons plus 10 fit experiment seasons);
  `calibration/targets.json` with 62 targets, each with sourced pass, warn, and CI bands, an exact source, and
  a note; Markdown and JSON reports; a 20-season CI run; the in-app runner in the hidden developer tools.
- Sim and league changes: lead protection and chasing a deficit (D-18), checkdowns, throwing to the sticks,
  turnover return breakaways, wind on every throw, a field goal curve with a knee, injury carry-over in
  replays (D-17), and roster balance (D-19). Fifteen logged changes, C-1 to C-15.
- Evidence:
  - `npm run check`: pass, 319 unit tests. `npm run layout`: 56 passed in Chromium (WebKit runs in CI).
  - 100 seasons on seed 1 and on seed 2: 62 pass, 0 warn, 0 fail, 12 info, 4 not measured yet. Seed 3
    warns on the receiving yards leader and 4,000-yard passers (10 leagues per run).
  - Seed 1: home teams win 54.4% by +1.6; 22.7 points per team; 50% one-score games, 24.5% blowouts, 6.3%
    overtime; favorites win 65%; margin sd 13.2; win sd 2.96; 5 perfect or winless teams per 100 seasons;
    64.9% completions, 7.1 per attempt, 4.3 per carry; passing leader 5,046; fit effect 5.2%.
- Reviews: the ui-reviewer found 11 problems in the developer tools, all fixed. The spec-reviewer found leader
  bands spanning single seasons, bands wider than their sources, missing notes, test gaps, and a double-counted
  protection measure; all fixed, which surfaced hot leaders, easy 40-yard kicks, and too few fourth-down
  tries, retuned in C-12 to C-15.
- Decisions: D-17 to D-19. Known gaps: pass volume barely tracks game script; games lost has no sourced
  target; multi-season metrics wait for M10; more developer tools later (docs/KNOWN-ISSUES.md).
