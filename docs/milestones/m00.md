# M0: Repository, tooling, and the single-file build

## Plan
1. Tooling (TypeScript strict, ESLint, Prettier, Vitest, `npm run check`): proven by `npm run check` passing.
2. Seeded PRNG with sub-streams, weighted-seed nonce, and fixed mode, plus `src/engine/tuning.ts`: proven by rng unit tests (same seed in fixed mode gives the same sequence; sub-streams independent).
3. Style guide stylesheet split into `src/styles/`, font embedder, Vite single-file build to `dist/game.html` and `build:debug`: proven by `npm run build` and an embedder idempotence test.
4. Theme and layout runtime (32 palettes, `applyTeamTheme`, Day and Night, Auto layout with manual override): proven by the 32 x 2 theme-matrix unit test and layout-rule unit tests.
5. App shell with hash routing (sidebar, rail, top bar, tab bar, More menu, placeholder screens, Settings): proven by Playwright layout tests at 390x844, 834x1194, 1440x900 in Day and Night.
6. IndexedDB wrapper and worker bootstrap with a progress protocol: proven by fake-indexeddb and protocol unit tests, and a Playwright test that runs a worker job in the built file.
7. Offline test and CI (lint, type check, unit tests, build, layout in WebKit and Chromium): proven by the offline Playwright test and a green CI run.
