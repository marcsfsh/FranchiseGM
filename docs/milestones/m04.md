# M4: Game simulation v1

## Plan
1. On-field rules in the rule set (clock, timeouts, overtime, kickoffs, PATs and two-point tries, fair catches, penalty definitions with yardage and automatic first downs) and the sim sliders of spec 22.3 as league settings with neutral defaults: proven by rule set tests (save format 3).
2. Game setup: depth charts from snap-ordered lineups with backups, per-player action composites with fit and cohesion, the auto game plan, weather from the venue's climate, home field sources (crowd, travel, rest), and team form: proven by unit tests.
3. The play loop (spec 8.3): situations, the clock and two-minute warning, drives and scoring, fourth-down, two-point, and timeout decisions from coach tendencies, personnel and packages, and play calls from tendencies with adaptive shifts: proven by full-game invariants (clock, downs, score).
4. Resolution: pass (protection, target, throw, catch, YAC, interceptions, sacks, scrambles), run (blocking, lanes, carrier, fumbles), and special teams (kickoffs, returns, punts, field goals, extra points, onside kicks), with abilities triggered at each step, penalties from the rule set, injuries, fatigue, and rotations: proven by league averages over many games near NFL 2021-2025 levels and a rule change test.
5. Outputs (spec 8.8): box score, stat lines, scoring summary, drive summaries, and recap v1: proven by consistency tests (team totals equal player sums, scores equal scoring plays).
6. The sim in the worker, under 100 ms a game, with fixed mode exact and weighted mode similar but not identical: proven by a Node timing test, a Playwright worker test, and repeatability tests.
7. Measured situation profiles (spec 7.5) for the named schemes, cached as generated data and blended for blends, replacing M3's estimates: proven by profile tests.

## Report
- Built: the spec 8.3 play loop (situations, coaching decisions, personnel and packages including goal line,
  play calls with adaptive and halftime shifts, pass, run, and special teams, penalties and ejections from the
  rule set, injuries, fatigue and rotation, weather, home field, and form); game rules and sim sliders in league
  settings (save format 4); box scores, scoring and drive summaries, recap v1; the simGame worker job; measured
  situation profiles.
- Evidence:
  - `npm run check`: pass, 278 unit tests. `npm run layout`: 41 passed in Chromium (WebKit runs in CI).
  - About 10 ms a game in Node, under 100 ms in the browser worker. Totals equal player sums, scores equal
    scoring plays, and time of possession equals the game clock.
  - Fixed mode replays exactly; weighted mode differs a little; rule changes move results in tests.
  - 272 games: 23.6 points, 62.3 plays, 63.5% completions, 7.1 yards per attempt, 2.4% interceptions, 6.5%
    sacks, 4.2 per carry, 38% on third down, 60% red zone TDs, 55% home wins, about 4% overtime.
  - tests/sim/endgame.test.ts and special.test.ts start sims from set situations to prove overtime, clock
    management, and every game rule field.
- Reviews: two spec reviews; the first found overtime, clock, and rule gaps, the second (25,000 instrumented
  games, no flow violations) seven smaller ones. All fixed.
- Calibration: the harness arrives in M6; points run a little high, completions and penalty yards low.
- Decisions: D-8 to D-13.
- Known gaps: inactives, snap limits, and situational subs (M7); crowd hype (M16); muffed punts, blocked
  field goals, roughing the kicker, and the 10-second runoff.
- Final commit: ea5cf29d46950feae0a5d5b1d025ddac1be22a63, CI red (run 15); CI was next green in M7.
