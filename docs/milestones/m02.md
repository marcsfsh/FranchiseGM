# M2: League creation and saves

## Plan
1. League state model with a save schema version, and `createLeague` for the fictional path (start-only settings from spec 3.2, defaults for the rest): proven by unit tests (valid rosters, seed repeatability, JSON-safe state).
2. Save store on IndexedDB (league list plus full state, autosave hook, persistence request) and gzipped JSON export and import with the "no migration" message: proven by round-trip tests in tests/saves (save and load, export and import give identical state; an old schema is refused with a clear message).
3. League creation runs in the worker with progress: proven by a worker protocol test.
4. Start screen (league list with team, season, week, edited flag; continue, export, delete, import) and the new league form; league navigation appears once a league is open; the theme follows the user's team: proven by Playwright tests at three sizes.
5. Reload and continue: proven by a Playwright test that creates a league, reloads, and continues it.

## Report
- Built: the league state model (save format 1) and league creation on the fictional path; an IndexedDB save store with one slot per league, the autosave hook, the persistence request, and the last opened league; gzipped JSON export and import with the "no migration" message; league creation in the worker with progress and cancel; the Leagues screen, the new league form, the team hub, and the League card in Settings.
- Evidence:
  - `npm run check`: pass, 187 unit tests. `npm run layout`: 36 passed in Chromium (WebKit runs in CI).
  - Create, reload, and continue: passed 36 of 36 repeats after the last opened league moved to IndexedDB.
  - Save and load, export and import, and both chained give strictly equal state; damaged files and other save formats are refused with clear messages, and saves from other versions still export.
  - A new league builds in about 255 ms in Node; it is 5.5 MB of JSON and a 678 KB export.
- Reviews: the ui-reviewer found 16 problems in the new screens (busy states, focus after delete, cancel while building, failed saves on create and switch, reflow at 320 px with 200% text, copy); all fixed. The spec-reviewer found both done-when items met and 4 gaps (import validation, exporting saves from other versions, the Safari reminder, strict round-trip asserts); all fixed.
